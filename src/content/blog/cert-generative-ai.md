# Generative AI Fundamentals

**Completed:** Jul 2024 (Placeholder)  
**Issuer:** Udacity  

## Overview
This program covers the fundamentals of Generative AI, including working with Large Language Models (LLMs), prompt engineering, and building AI-powered applications.

## Key Learnings & Concepts
- **LLM Architecture:** Understanding the underlying mechanisms of transformers, attention, and tokenization.
- **Prompt Engineering:** Mastering advanced prompting techniques like Few-Shot, Chain-of-Thought, and ReAct to guide model outputs effectively.
- **RAG Systems:** Building Retrieval-Augmented Generation systems to anchor LLMs to external knowledge bases and reduce hallucinations.
- **Application Integration:** Utilizing frameworks like LangChain and LlamaIndex to build end-to-end AI applications and APIs.

- Generative AI
