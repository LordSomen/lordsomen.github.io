# Microsoft Certified: Azure Data Scientist Associate

**Completed:** Aug 2025  
**Issuer:** Microsoft  
**Credential ID:** 75FBF18E85783EFE  

## Overview
This certification demonstrates expertise in implementing and running machine learning workloads on Microsoft Azure. It validates the ability to build and deploy ML models using the Azure Machine Learning workspace.

## Key Learnings & Concepts
- **Data Preparation:** Ingestion and processing of large datasets using Azure Synapse Analytics and Data Factory.
- **Model Training:** Utilizing automated machine learning (AutoML) and writing custom Python scripts for training robust models.
- **Model Deployment & MLOps:** Deploying models as scalable REST APIs on Azure Kubernetes Service (AKS) and managing model lifecycles using MLflow.
- **Responsible AI:** Implementing fairness evaluations and feature importance explanations for transparency in model predictions.

## Skills Acquired
- Data Science
- Azure Machine Learning
- Model Deployment & MLOps
- Python & Data Analysis
