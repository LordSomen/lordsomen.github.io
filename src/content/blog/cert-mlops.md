# Machine Learning Engineering for Production (MLOps)

**Completed:** Jul 2024 (Placeholder)  
**Issuer:** Coursera (DeepLearning.AI)  

## Overview
This specialization covers the foundational concepts of MLOps, including deploying machine learning models in production, managing data pipelines, and maintaining model performance over time.

## Key Learnings & Concepts
- **Model Deployment Strategies:** Exploring shadow mode, canary deployments, and blue-green deployments for safe AI rollouts.
- **Data Pipelines:** Designing robust data extraction, validation, and transformation pipelines using tools like TensorFlow Extended (TFX).
- **Monitoring & Maintenance:** Identifying data drift, concept drift, and establishing retraining pipelines to keep models accurate in production.
- **Infrastructure:** Understanding edge versus cloud deployment tradeoffs, optimizing inference speed, and managing compute resources.

## Skills Acquired
- Model Deployment
- Data Pipelines
- CI/CD for ML
- Model Monitoring
